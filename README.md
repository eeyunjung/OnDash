# OnDash - 내 차 가이드 AI (실서비스)

> **2025년형 현대 아이오닉 5 NE1 기준 차량 공식 매뉴얼 RAG AI 안내 & UT 3자 답변 비교 서비스**

---

## 🚗 1. 서비스 개요

**OnDash**는 한국 판매 사양의 **2025년형 현대 아이오닉 5 NE1 (ccNC 인포테인먼트)** 차량을 기준으로, 운전자가 마주치는 다양한 차량 이상 및 도로 상황에서 공식 취급설명서에 기반한 안전한 행동 요령을 제공하는 대화형 차량 가이드 서비스입니다.

동시에 UT(사용성 테스트) 환경에서 다음 세 AI 시스템의 답변을 동일한 가상 상황에서 비교 검토할 수 있습니다:
1. **우리 서비스 (OnDash)**: 공식 취급설명서 근거 기반 단계별 절차 안내
2. **ChatGPT**: 일반 LLM 스타일 안내
3. **Gemini**: 일반 LLM 스타일 안내

---

## 🛡️ 2. 핵심 원칙

- **근거 없는 추측/환각(Hallucination) 배제**: 확인되지 않은 매뉴얼 내용, 페이지 번호, 가짜 출처를 절대 생성하지 않습니다.
- **연식/사양 불일치 시 단정 금지**: 공식 근거가 없으면 *"등록된 공식 자료에서 이 상황을 뒷받침하는 근거를 찾지 못했습니다."* 로 안내합니다.
- **답변 순서 체계화**:
  1. 지금 우선할 행동
  2. 그 행동이 필요한 이유
  3. 상황에서 확인할 조건
  4. 하지 말아야 할 행동 또는 주의점
  5. 다음 단계 (정비소, 긴급출동 등)
  6. 판단할 수 없는 부분
  7. 근거 (문서명, 해당 절/페이지, 공식 URL, 확인일)

## 📱 3. 주요 화면 및 기능

- **홈 대시보드 (`HomeTab`)**:
  - 실시간 가상 상황 카드 및 상황 전환 모달 연동
  - 질문 전/후에 따른 **맥락 맞춤형 예상 질문** 자동 위치 전환
  - 유려한 등장 인터랙션 및 햅틱/클릭 피드백
- **대화형 AI 가이드**:
  - 질문에 대한 즉시 답변 및 공식 인용 출처 표시
  - 3자 답변 비교(우리 서비스 vs ChatGPT vs Gemini) 모달 지원
- **히스토리 (`HistoryTab`)**: 이전 질문 및 답변 기록 확인
- **마이페이지 (`MyPageTab`)**: 차량 정보 및 개인화 설정

## 🚀 4. 로컬 실행 방법

### 요구 사양
- **Node.js**: v22.0.0 이상 (내장 `node:sqlite` 사용)
- **NPM**: v10 이상

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 프로덕션 빌드 (Vite)
npm run build

# 3. 통합 서버 실행 (Express/Node HTTP + Vite dist)
npm start

# 접속 주소: http://localhost:3000
```
